# ポケスリ個体チェッカー

ポケモンスリープの「ポケモンの詳細画面」のスクショから、せいかく・サブスキルなどを読み取って、
理想個体の何%か（だいふくさん式のランク 増田・SS〜D）と、1日に稼ぐエナジー・食材数などを出す個人用のWebアプリです。

- スクショの文字読み取りは端末内（Tesseract.js）で行います。画像はどこにも送信されません。
- 読み取った個体の履歴は、使っている端末のブラウザの中にだけ保存されます。
- iPhoneでは Safari で開いて「共有 → ホーム画面に追加」すると、アプリとして全画面で使えます。オフラインでも動きます。

## しくみ

- ランクは、だいふくさんの[ポケモンスリープ個体値チェッカー](https://www.pokemonsleepdaifuku.com/checker/)の考え方で出します。
  せいかく・サブスキルが1日のエナジーをどれだけ増やすかを1つずつ計り、その合計が「理想個体」の何%かを求め、
  公開されている9分類・Lv60／Lv70の基準でランクを付けます。進化前のポケモンは最終進化の姿で評価します。
  計算式は非公開のため、公開されている結果に合わせて重みを調整しています（完全には一致しません）。
- 「サブスキル・せいかくの向き」は nitoyon さんの「個体評価」（きのみ・食材・スキルの100点満点）と同じ計算です。
- 計算（SP・おてつだい時間・1日のエナジーなど）とポケモンのデータは
  [nitoyon/pokesleep-tool](https://github.com/nitoyon/pokesleep-tool) の計算部分をそのまま同梱しています。
- ムウマ・ムウマージ（2026年10月26日登場）のデータとマジカルフレイムの効果量は
  [RaenonX ポケスリ攻略ツール](https://pks.raenonx.cc/) のデータを使っています（出典）。
- 読み取りの確認として、画面に出ているSP・おてつだい時間と計算結果が一致するかを見ています。
  ニックネームの個体も、SPとおてつだい時間から種類を割り出します。

## ファイル

- `index.html` … 画面
- `assets/` … アプリ本体（`app.js` 画面処理 / `engine.js` 評価 / `ocr.js`・`ocr-parse.js` 読み取り / `nito.js` 計算 / `data.js` ポケモンデータ）
- `vendor/` … 文字認識エンジンと日本語モデル
- `sw.js`・`manifest.webmanifest`・`icons/` … ホーム画面アプリ用
